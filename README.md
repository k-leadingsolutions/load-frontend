# LOAD Frontend

Premium technology-enabled laundry and delivery MVP frontend.

## Foundation included

- React + TypeScript + Vite frontend scaffold
- Tailwind CSS design tokens in LOAD blue and white
- Role-based route foundation for public, customer, operations, driver, and admin experiences
- Typed domain models, service interfaces, mock API contracts, and mock async services
- MVP blueprint covering route map, screen inventory, folder structure, design system, pricing, order statuses, and eight-week backlog
- Vitest and React Testing Library setup

## Scripts

- `npm run dev`
- `npm run build`
- `npm run typecheck`
- `npm run lint`
- `npm run test`
